Press `?` to list the shortcuts, or Ctrl+K to open the command palette. On macOS, Ctrl in these shortcuts is Cmd.

## Find a command

Ctrl+K opens the palette. Type to search every command, page and shortcut, then press Enter to run one. Each result shows its shortcut.

## Default shortcuts

| Shortcut | Action |
| --- | --- |
| Space | Play or pause |
| Ctrl+→ / Ctrl+← | Next or previous song |
| Shift+→ / Shift+← | Seek forward or back |
| Ctrl+↑ / Ctrl+↓ | Volume up or down |
| M | Mute |
| S / R | Shuffle / repeat |
| F | Favourite the playing song |
| Q | Show or hide the queue |
| N / L / V | Now Playing / lyrics / music video |
| [ / ] / \ | Lyrics earlier / later / reset |
| Shift+L | Full-Screen Lyrics |
| ↑ / ↓ | In Full-Screen Lyrics, the previous or next line |
| ← / → | In Full-Screen Lyrics, back or ahead 5 seconds |
| Home | In Full-Screen Lyrics, the start of the song |
| Escape | Close Now Playing |
| Ctrl+Shift+M | Mini player |
| Ctrl+Shift+E | Equaliser |
| / or Ctrl+F | Search |
| Ctrl+N | New playlist |
| Ctrl+B | Show or hide the sidebar |
| Ctrl+, | Settings |
| Ctrl+1 … 9 | Go to the sidebar's main pages, in order |
| Alt+1 … 9 | Go to the library pages, in order |
| Alt+← / Alt+→ | Back or forward (Cmd+[ and Cmd+] on macOS) |
| Ctrl+K | Command palette |
| ? | List the shortcuts |

On Linux and macOS, `?` needs the focus in the window. Press Tab first if it does nothing.

## Change a shortcut

1. Open Settings → Shortcuts.
2. Select a shortcut and press the new keys. Escape cancels and Backspace removes the shortcut.
3. If another command already uses the keys, Sona shows the conflict.

Choose Reset to default on a shortcut, or Reset all, to return to the defaults.
