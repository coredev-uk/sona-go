Sona is in early development, not a finished product. You need an Apple Music subscription. It is built first for Linux, and also runs on macOS (Apple silicon) and Windows (x64).

## A native app

Sona's interface is drawn on the GPU by [MyGo](https://github.com/egoist/mygo) over GTK3, AppKit or Win32, with no web view. On Linux you get media controls, notifications and a tray. On macOS and Windows you get media keys and Now Playing.

## Make it yours

Sona's board is neutral so album covers show true colour, and amber marks what is playing. Twelve [themes](/guide/themes/) come with it, and you can write your own as a JSON file. Control the running app from a terminal or status bar with the [command line](/guide/cli/), or use the small mini player.
