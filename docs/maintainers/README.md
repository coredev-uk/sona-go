- [repository.md](repository.md): branch protection, release automation, self-update builds, pinned inputs and dependency updates.

- [proposals/](proposals/): plans for work that isn't done yet. Status lives on GitHub.
- [redesign/](redesign/): the notes and measurements of the page redesign (#277).
